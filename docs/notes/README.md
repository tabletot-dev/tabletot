# Working notes folder

Brainstorms, half-thoughts, learnings, "I noticed this about X", meeting
prep, anything that isn't a decision yet.

Flat folder. No subfolders until a pattern emerges. If you find yourself
writing four notes about the same thing, *then* promote it to its own
folder or a runbook in a new top-level folder.

Use tags inline: `#open-question`, `#deferred`, `#sarvam-quirk`, etc.
